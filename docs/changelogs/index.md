# Changelog

All notable changes to the support projects (since 2026-02-19) are documented in these files. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). These projects adhere to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) with the following convention:

They use versioning in the format `v{X.Y.Z}`, where X, Y, and Z are integers:
* **X and Y** are determined by the `treeppl` version and used as-is by `treepplr` and `treeppl-python` (e.g., both `treepplr v1.2.0` and `treeppl-python v1.2.1` rely on `treeppl v1.2`).
